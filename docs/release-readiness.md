# 发布候选验收

This file records historical RC checks and later release evidence. For the current 0.2.1 installation steps and support limits, use the [NAS GUI guide](nas-gui-install.md) and [compatibility notes](compatibility.md). A regular release does not establish compatibility with untested hardware.

版本：0.2.1。日期：2026-10-14。

## 已完成

- 自有代码白名单整理，未复制私有 runtime、真实设备、订阅或厂商固件 JavaScript。
- MB 十进制单位和 JavaScript 语法检查。
- 54 项 Python 测试通过，包括设备规则、IP 重用、订阅失败恢复、流量采样、路由器模拟、配置初始化及 HTTP 认证。
- NAS 上 Docker Compose v5.1.3 的 config --quiet 校验通过，只校验候选配置，没有创建网络或变更运行服务。
- 独立发布检查镜像构建成功（不覆盖运行镜像）；无网络、丢弃全部 capabilities 的容器内 54 项测试通过。
- 隔离容器中 dnsmasq --test、面板启动、/health 和登录验收通过，DHCP 保持关闭。
- 虚构设备演示已检查开关，已保存演示截图。
- 初始化默认关闭 DHCP，生成独立面板密码和随机核心密钥。
- 中文 README、安装/恢复、兼容矩阵、流量口径、贡献和依赖说明。
- 两周运营计划、首发文案和演示脚本。

适合发布为试用 RC 的前提是明确上述支持范围，并完成下面的干净联网接管验收。没有干净安装验收之前不宣传稳定版、所有路由器兼容或一键接管。

## 发布后排查待确认

双网卡电脑已观察到实际代理流量；平板持有旧租约的问题已在原环境完成重入验收：用户确认只输入 Wi-Fi 密码后可访问；新私人 MAC 的分流由现场重新开启。没有实现跨随机 MAC 身份识别或自动授权继承。不能将开关/规则启用当作接入成功。补充说明和文案目前仅在rc.2 更新；rc.1 已由现有发布替换。

rc.2 已适配 access_status.py，加入 MAC/IP 有效租约和三分钟核心连接区分。DHCP authoritative 默认 false，启用需额外确认唯一 DHCP。源代码测试增至 64 项；镜像、离线启动和两种 DHCP 协议路径由 GitHub CI 验证。

## rc.5 手动 NAS 安装

新增中英文浏览器安装入口、网络识别、地址检查、私有配置事务写入、正式 Compose 下载，以及面板 DHCP 接管/停止操作。102 项本地源码测试通过，包含来源与 CSRF、安装访问码限速、固定地址和 NAS 别名排除、失败后无部分配置、已部署保护及 DHCP 条件校验。虚构浏览器流程已实际保存、下载生成配置并验证英文说明。

已核对绿联 UGOS Pro 的 Docker 项目创建、存放路径、Compose 导入（从本地电脑/从 NAS）入口。隔离镜像、真实宿主接口识别、最终 CI 和公开镜像拉取的结果在完成后追加；不以模拟结果代替干净实机 LAN 部署。其他厂商、ARM、IPv6 和自动故障切换不在已验收范围。

绿联 DXP4800 上以独立测试镜像、无网络并丢弃全部 capabilities 的容器完成首轮 101 项测试（10 项 Node 运行测试跳过；本机有 Node 的最终 102 项均通过），离线面板与安装向导启动、健康和登录检查通过，DHCP 未开启。setup、正式源码 Compose 和浏览器实际下载的虚构 Compose 三份解析通过。host 网络只读预检识别既有 bond0 和实际网段；单独 NET_RAW 检查验证已有网关地址被 ARP 判为占用，没有修改现有接口、DHCP 或运行容器。

最终候选镜像重新构建后，NAS 隔离容器完成 102 项源码测试（同样跳过 10 项 Node 运行检查）；本机 102 项全部通过。附加离线场景把 runtime 的目录/文件设为另一个 UID 所有，保留 0700/0600 权限，仅给予 CHOWN 和 DAC_OVERRIDE 完成夹具准备与面板启动/登录验证。浏览器最终导出文件确认包含两服务 DAC_OVERRIDE、无环境变量占位和凭据。安装中英文表单与窄窗口无横向溢出，虚构 DHCP 接管按钮状态也已验证。现网核心、DHCP、聚合和设备偏好未改动。

完整 CI 与镜像发布由对应 Actions 和新版本 Release 提供证据；本地结果不代替该记录。原有硬件、干净 LAN、IPv6 和故障切换的验证范围保持不变。
