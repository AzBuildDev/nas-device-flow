# 流量与统计

单位统一采用十进制：kB = 1,000 B，MB = 1,000,000 B，GB = 1,000,000,000 B。MB/s 是每秒字节数，Mbps 是每秒兆比特数，两者相差 8 倍。

核心实时流量包含经过 Mihomo 的直连和代理连接，不代表整条宽带或整个 LAN。核心累计由核心提供，重启后归零；三分钟图表保存在内存里，面板后端重启后重新开始。

设备名称旁的代理流量来自 /connections 的连接 UUID 和上传下载计数增量，仅匹配实际代理节点，排除 DIRECT。首次见到的已有连接以当时计数为基线，避免把开始采样前的流量算进去。依 MAC 关联设备，IP 重用或归属不明确时不将流量分配给错误设备。

采样结果约每 30 秒落盘，正常退出保存；异常断电可能丢失最近未保存数据。已结束但采到的连接仍保留累计。短于采样间隔的连接和停机期间可能漏计。设备统计保存在 runtime/control-center，不因打开网页清零。它不能用于计费，也不等同于订阅服务商的套餐使用量。
